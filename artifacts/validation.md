# SeedClock implementation and validation

Completed 2026-10-17. This is a worker report of the stated checks, with no independent certification.

## Scope and assumptions

One static, hash-navigated React/TypeScript/Vite site, exported to `dist/` with relative assets. The supplied Ethereum mainnet addresses are used verbatim. The visual idea is the collection’s animated vector clocks on a restrained charcoal canvas, with amber mint controls and teal seed details. Light mode, keyboard use, and reduced motion are supported.

The gallery uses the explicitly allowed static preview set, with original SVG animation. All six originals were compared byte for byte with mainnet `tokenURI` output; every comparison matched. The OpenSea URL remains the requested, clearly labelled future link. No deployment, publication, real signature, mint, or claim was performed.

## Limitations and completion

Complete for the stated static-site implementation and Chromium validation scope. Real mainnet writes were not tested. Physical wallet-app deep-link handoffs, Coinbase passkey authorization, native Safari/WebKit behavior, screen-reader output, native zoom, RTL, and pseudo-localization remain unverified. The supplied browser tool failed to initialize its read-only cache. Direct Playwright Chromium ran successfully; WebKit launch failed with missing host libraries including `libgtk-4.so.1`. This is an environment limitation, not a request for credentials or approval.

Receipt state is held in the active page session. Reloading does not restore a pending transaction, so wallet activity should be checked before resubmitting. The site leaves a submitted transaction pending if confirmation cannot be read and provides Etherscan/manual-check links. Public RPC services and wallet providers remain external availability dependencies. ERC-20 royalty claims are intentionally outside the site’s ETH-only claim button and are explained with a distributor link. OpenSea remains the expressly permitted placeholder. Hosting/publication is outside this deliverable.
